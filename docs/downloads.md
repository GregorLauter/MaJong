# Open your Mah Jong download

[← Back to Mah Jong](../README.md)

Download the file for your computer from the GitHub release linked in the README.
Until that release is published, the prepared download links will not work.
Public release downloads need no GitHub account. These are portable test bundles,
not signed installers. Extract the downloaded archive before opening the app.

## Mac

For Apple Silicon Macs (M1, M2 and newer), running macOS 13 or later:

1. Download the Mac version and open the ZIP file.
2. Find **Mah Jong.app**. If another ZIP is inside, open that first.
3. Drag **Mah Jong.app** into your **Applications** folder.
4. Open **Mah Jong** from Applications or Spotlight.

This download is not an Intel Mac build.

## Windows

For a 64-bit Windows PC:

1. Download the Windows version.
2. Right-click the ZIP and choose **Extract All**. If another ZIP is inside,
   extract that too.
3. Keep the extracted **Mah Jong** folder together.
4. Open the folder and double-click **Mah Jong.exe**. Windows may show it simply
   as **Mah Jong**, with the application icon.

Do not open the app from inside the ZIP or move the EXE out of its folder.
A normal installer and Start-menu shortcut are planned for a later step.

## Linux

This test version is built for Ubuntu 24.04 on a 64-bit Intel/AMD computer.
Compatibility with other distributions has not yet been verified.

1. Download the Linux version and extract the archive using your file manager.
2. Keep the extracted **Mah Jong** folder together.
3. Open the folder and launch the **Mah Jong** executable.

Some desktops may ask whether to run an executable file. If your desktop does
not offer a way to launch it, report your Linux version before proceeding; a
one-click install package is not available yet.

## If your computer blocks the app

These early builds do not yet have a verified publisher signature. macOS or
Windows may display a security warning. If that happens, stop and share the
exact message so we can work through the installation test together.

## Your first game

Enter four player names, then enter each hand value and select the winner.
Click **Settle hand** (called **Settle round** in older builds). To keep your progress, use **Save game** and choose a
folder you can find again. Use **Open game** to continue later.

## Deutsch

Lade das passende Paket über den Release-Link in der README herunter. Vor der
Veröffentlichung funktionieren diese vorbereiteten Links noch nicht. Öffentliche
Release-Downloads benötigen kein GitHub-Konto.

- **Mac (Apple Silicon, macOS 13+):** ZIP öffnen, **Mah Jong.app** nach
  **Programme** ziehen und dort öffnen. Intel-Macs werden nicht unterstützt.
- **Windows (64-Bit Intel/AMD):** ZIP mit **Alle extrahieren** entpacken. Den
  gesamten Ordner zusammenlassen und **Mah Jong.exe** doppelklicken.
- **Linux (64-Bit Intel/AMD):** TAR.GZ im Dateimanager entpacken, den Ordner
  zusammenlassen und **Mah Jong** starten. Gebaut für Ubuntu 24.04; andere
  Distributionen sind noch nicht geprüft.

Die Testpakete sind noch nicht mit einem verifizierten Herausgeber signiert.
Bei einer Sicherheitswarnung oder Startproblemen bitte den genauen Meldungstext
und dein Betriebssystem weitergeben. Es sind noch keine Ein-Klick-Installer.

Vier Namen eingeben, vier Handwerte eintragen, Gewinner auswählen und
**Settle hand** anklicken. **Save game** speichert, **Open game** lädt den Spielstand.
