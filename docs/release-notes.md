# Mah Jong 0.1.0 — desktop test version

Offline score calculation and settlement tracking for four players. Enter hand
values, select the winner, and keep totals, East/seat Winds and hand history.
Games can be saved locally. English/German rules are included in the app and PDF.

Download the attachment for your computer:

- **Windows:** `Mah-Jong-Windows-x64.zip` — extract all, keep the folder together,
  then open `Mah Jong.exe`.
- **Mac:** `Mah-Jong-macOS-arm64.zip` — Apple Silicon, macOS 13+. Extract and drag
  `Mah Jong.app` into Applications. Intel Macs are not supported by this build.
- **Linux:** `Mah-Jong-Linux-x64.tar.gz` — Ubuntu 24.04 x64 target. Extract, keep
  the folder together, and launch `Mah Jong`.
- **Rules:** `Mah-Jong-rules.pdf` — English first, German below.

These are test bundles, not signed installers. macOS/Windows may warn or block
opening because the publisher is unverified. Other Linux distributions are not
verified. Report your operating system and exact error if the app does not open.
No Python installation is needed. This is a calculator, not a playable game.
